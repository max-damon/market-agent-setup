# Comprendre l'audience

1. Identifier les données disponibles : entretiens, avis, tickets, enquêtes, recherches, statistiques de campagne ou brief du client. Noter la date, l'échantillon et les biais de collecte.
2. Séparer les verbatims et comportements observés des interprétations. Si aucune donnée directe n'existe, produire des hypothèses de segment et un plan de validation, sans fabriquer de citations.
3. Pour chaque segment utile, résumer situation, problème, déclencheur, objections, critères de choix, canaux pertinents et langage attesté.
4. Chercher les divergences entre segments et les contre-exemples ; éviter un portrait unique qui efface les différences importantes.
5. Livrer une fiche exploitable pour un brief : segments prioritaires, messages possibles, preuves manquantes, sources et niveau de confiance.

Ne pas conserver de données personnelles identifiantes dans `memory.md`. Les informations durables validées peuvent y être résumées sans verbatims sensibles.
